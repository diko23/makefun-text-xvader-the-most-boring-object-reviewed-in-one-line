Entry for [The Most Boring Object, Reviewed in One Line](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3) on [make.fun](https://make.fun).

This entry outputs a single-line, deadpan product review of a spare shirt button and its quiet, untouched existence inside a household junk drawer.

## Run it

Requires Node 22.18+ (no external dependencies). Writes the single-line UTF-8 review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaulting to `/output/entry.txt`):

```sh
node main.ts
```

In the grading sandbox, the entry is executed as:

```sh
node /bot/main.ts
```
